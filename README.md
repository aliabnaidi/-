# Ali Al-Aydi — Cybersecurity Portfolio

A custom responsive personal portfolio built with pure HTML, CSS and JavaScript.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Customize first
- Replace placeholder university, certificates, projects and links in `index.html`.
- Put your real CV at `assets/Ali-Al-Aydi-CV.pdf`.
- Put profile/certificate images under `assets/`.
- Update the email, GitHub, LinkedIn and TryHackMe links.
- Adjust skill percentages in `css/style.css` if you want them to represent your actual level.

No framework or build step is required.
